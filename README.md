# VIT CGPA Calculator

A free, client-side CGPA calculator for VIT (Vellore Institute of Technology) students. Enter your course grades and credits — the calculator computes your CGPA instantly, right in the browser. No signup, no data leaves your device.

## Features

- Add courses with credits and grades
- Instant CGPA calculation as you type
- Runs 100% client-side — private by design
- Single HTML file — works offline

## Tech Stack

- **HTML5**, **CSS3**, **JavaScript** — everything in `vit-cgpa-calculator.html`

## Quick Start

Just open the file in a browser:

```bash
git clone https://github.com/girishlade111/vit-cgpa-calculator.git
cd vit-cgpa-calculator
# open vit-cgpa-calculator.html in your browser
```

Or serve it locally:

```bash
npx serve .
```
